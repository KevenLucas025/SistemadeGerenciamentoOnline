Ajuda sobre a planilha

Confira as orientações antes de realizar o cadastro em massa.

1. Formato da planilha
  • O arquivo deve estar no formato .xlsx.
  • Utilize a primeira aba da planilha para inserir os usuários.
  • A primeira linha deve conter os nomes das colunas.
  • Não altere os nomes dos cabeçalhos. O modelo disponibilizado pelo sistema possui proteção para evitar modificações acidentais.
  • Cada linha deve representar um usuário.
  • O limite máximo é de 500 usuários por importação.
  • Não insira usuários além do limite disponibilizado no modelo.
  • A senha será gerada automaticamente pelo sistema. Não é necessário informar uma senha na planilha.

A proteção dos cabeçalhos e o limite de registros ajudam a preservar a estrutura da planilha e evitar problemas durante a importação.

Para evitar incompatibilidades, baixe e utilize sempre o modelo de planilha disponibilizado pelo próprio sistema.

2. Colunas da planilha
Nome

Informe o nome completo do usuário que utilizará o sistema.

Usuário

Informe o nome de usuário utilizado para acessar o sistema. O campo aceita até 11 caracteres

Não deixe o campo em branco e respeite o limite de caracteres.
CEP

Informe um CEP válido, com ou sem formatação.

Exemplos: 00000-001 ou 00000001. Deve conter exatamente 8 dígitos.
Endereço

Informe o logradouro do endereço do usuário.

Exemplo: Rua Antônio Lucas.
Número

Informe o número do endereço utilizando um número inteiro.

Exemplos: 105, 400 ou 35. Caso não exista número, deixe a célula em branco.
Cidade

Informe a cidade de residência do usuário.

Exemplo: Campinas.
Bairro

Informe o bairro do endereço.

Exemplo: Centro, Jardim São Domingos.
Estado

Informe apenas a sigla do estado.

Exemplos: SP, MG ou RJ.
Complemento

Informe o complemento do endereço, caso exista.

Exemplos: Bloco A, Apartamento 31 ou Casa 2. Caso não exista, deixe a célula em branco.
Telefone

Informe um número de telefone ou WhatsApp válido.

Exemplos: (11) 00000-0001 ou (19) 00000-0002. Utilize um número exclusivo, conforme as regras de cadastro do sistema.
E-mail

Informe um endereço de e-mail válido e exclusivo. E-mails já utilizados em outros cadastros não serão aceitos.

Exemplos: usuario1@exemplo.com ou usuario2@exemplo.com.
Data de Nascimento

Informe uma data de nascimento válida.

Exemplos: 29/10/2000, 26/01/2000 ou 09/09/2002. Utilize o formato de data aceito pelo modelo.
RG

Informe um RG válido, com exatamente 9 dígitos conforme a validação utilizada pelo sistema.

Exemplos: 00.000.000-1 ou 000000001. O documento deve ser exclusivo.
CPF

Informe um CPF válido, com exatamente 11 dígitos O documento deve ser exclusivo.

Exemplos: 529.982.247-25 ou 52998224725.
CNPJ

Informe um CNPJ válido, com exatamente 14 dígitos O documento deve respeitar as regras de validação do sistema.

Exemplos: 11.222.333/0001-81 ou 11222333000181.
3. Cuidados importantes
  • Confira se todos os campos obrigatórios foram preenchidos.
  • Não utilize textos em campos que exigem números.
  • Verifique se os documentos informados são válidos.
  • Confira se não existem documentos ou e-mails duplicados.
  • Confira as datas antes de iniciar a importação.
  • Não altere a estrutura ou os nomes das colunas.
  • Verifique se os dados não possuem espaços desnecessários ou informações incompletas.
4. Como realizar o cadastro
  1. Baixe o modelo de planilha de usuários.
  2. Preencha os dados seguindo as orientações apresentadas.
  3. Clique em Abrir planilha e selecione o arquivo preenchido.
  4. Confira os usuários apresentados na tabela.
  5. Clique em Fazer o cadastro em massa.
  6. Aguarde o processamento e confira o relatório final.
  7. Consulte as credenciais geradas pelo sistema após a conclusão do cadastro.

Usuários com dados inválidos serão rejeitados individualmente. Isso significa que um registro com erro não impede o cadastro dos demais usuários válidos.

Utilize sempre o modelo disponibilizado pelo sistema, evitando criar uma planilha do zero.

O cadastro em massa permite importar até 500 usuários por vez. Caso tenha mais registros, divida os dados em várias importações.

5. Conferência antes de importar

Antes de iniciar o cadastro em massa, confira os seguintes pontos:

  • Todos os usuários possuem nome preenchido.
  • Os nomes de usuário respeitam o limite de 11 caracteres.
  • Os CEPs possuem exatamente 8 dígitos.
  • Os telefones e e-mails estão preenchidos corretamente.
  • As datas de nascimento são válidas.
  • Os documentos informados possuem a quantidade correta de dígitos.
  • Os documentos e e-mails não estão duplicados.
  • Os cabeçalhos permanecem iguais aos do modelo original.
  • Existem no máximo 500 usuários para importar.
6. Resultado da importação

Após o processamento, o sistema apresentará um relatório com o resultado do cadastro dos usuários.

  • Usuários cadastrados: quantidade de usuários importados com sucesso.
  • Usuários rejeitados: quantidade de usuários que apresentaram algum erro.
  • Identificação dos erros: indicação das linhas que precisam de correção e o motivo da rejeição.

Os usuários rejeitados poderão ter seus dados corrigidos na planilha e ser enviados novamente em outra importação.

As senhas são geradas automaticamente pelo sistema. Consulte e guarde as credenciais apresentadas após a conclusão do cadastro.
