Ajuda sobre a planilha

Confira as orientações antes de realizar o cadastro em massa.

1. Formato da planilha
  • O arquivo deve estar no formato .xlsx.
  • Utilize a primeira aba da planilha para inserir os usuários.
  • A primeira linha contém os nomes das colunas.
  • Não altere os nomes dos cabeçalhos, pois eles são protegidos por senha para evitar modificações acidentais e preservar a estrutura de importação.
  • Cada linha deve representar um usuario.
  • Por segurança e padronização, a planilha disponibiliza até 500 linhas para preenchimento por importação.
  • Não tente inserir usuários além do limite disponibilizado no modelo.
  • A senha será gerada automaticamente pelo sistema.Não é necessário informar senha na planilha.

A proteção dos cabeçalhos e o limite de 500 linhas ajudam a preservar a estrutura da planilha e evitar problemas durante a importação dos usuários.

Para evitar problemas, recomendamos baixar e utilizar o modelo de planilha disponibilizado pelo sistema.

2. Colunas da planilha
Usuário

Informe o nome do usuário. Este campo é obrigatório e aceita até 150 caracteres

Não deixe o campo em branco nem ultrapasse o limite de caracteres.
Quantidade

Informe um número inteiro igual ou superior a zero.

Exemplo: 1, 10 ou 250.
Valor Unitário

Informe o valor unitário do usuário em formato numérico.

Exemplo: 150 ou 150,50.
Desconto

Informe um número entre 0 e 100 representando a porcentagem de desconto.

Exemplos: 5 (5%), 10 (10%) ou 0 (sem desconto). Caso não exista desconto, deixe a célula em branco.

Não utilize textos como "Sem desconto", símbolos de porcentagem ou valores negativos.

Data do Cadastro

Informe uma data válida.

Exemplo: 29/10/2026.
Código do Item

O código é gerado automaticamente pelo sistema. Não é necessário preencher essa coluna. Caso preenchido o sistema irá ignorar e seguir gerando o código.

Cliente

Informe o nome de um cliente já cadastrado no sistema. Este campo é obrigatório e não pode ficar em branco.

O nome deve corresponder a um cadastro existente.
Descrição

Informe os detalhes ou características do usuario.

O limite máximo é de 5.000 caracteres.
3. Cuidados importantes
  • Confira se os valores numéricos estão preenchidos corretamente.
  • Não utilize textos em campos que exigem números.
  • Verifique se os clientes informados já estão cadastrados.
  • Confira as datas antes de iniciar a importação.
  • Não altere a estrutura ou os nomes das colunas.
4. Como realizar o cadastro
  1. Baixe o modelo de planilha de usuários.
  2. Preencha os dados seguindo as orientações acima.
  3. Clique em Abrir planilha e selecione o arquivo.
  4. Confira os usuários apresentados na tabela.
  5. Clique em Fazer o cadastro em massa.
  6. Aguarde o processamento e confira o relatório final.

usuários com dados inválidos serão rejeitados individualmente. O relatório apresentará as linhas que precisam de correção. E não tente criar uma planilha do zero, baixe e utilize a planilha disponibilizada pelo próprio sistema.

O cadastro em massa permite importar até 500 usuários por vez. Caso tenha mais usuários, divida os dados em várias planilhas.

5. Conferência antes de importar

Antes de iniciar o cadastro em massa, confira os seguintes pontos:

  • Verifique se todos os usuários possuem nome preenchido.
  • Confira se os nomes dos usuários não ultrapassam 150 caracteres.
  • Certifique-se de que os clientes informados já existem no sistema.
  • Confira se as quantidades são números inteiros e não negativos.
  • Verifique se os valores unitários foram preenchidos corretamente.
  • Confira se os descontos estão entre 0 e 100.
  • Verifique se as datas estão corretas e são válidas.
  • Certifique-se de que a descrição não ultrapassa 65.535 caracteres.
  • Não altere os nomes dos cabeçalhos da planilha.
  • Confira se existem no máximo 500 usuários para importar.
6. Resultado da importação

Após o processamento, o sistema apresentará um relatório com o resultado do cadastro dos usuários.

  • usuários cadastrados: quantidade de usuários importados com sucesso.
  • usuários rejeitados: quantidade de usuários que apresentaram algum erro.
  • Identificação dos erros: indicação das linhas que precisam de correção e o motivo da rejeição.

Os usuários rejeitados poderão ser corrigidos na planilha e enviados novamente em outra importação.
